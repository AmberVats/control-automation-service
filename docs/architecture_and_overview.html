2. Citizen Developer Framework (YAML)

Non-developers configure financial controls declaratively in YAML without writing Python code.

YAML Control Definition

Example: End-of-Day position & market value reconciliation.

name: eod_position_break
version: 2
component: reconciliation.two_way_match
description: EOD positions check
owner: product_control_analytics
schedule: "0 18 * * 1-5"

source:
  type: query_file
  query_file: queries/risk_positions.sql

target:
  type: query_file
  query_file: queries/books_positions.sql

keys:
  - as_of_date
  - instrument_id
  - book

compare:
  - quantity
  - market_value

tolerance:
  quantity:
    absolute: 0.0
  market_value:
    absolute: 50.0
    relative: 0.0001

Enterprise Governance & Hashing

Every YAML control is hashed via SHA-256 on registration to guarantee deterministic reproducibility across audit cycles.

3. Reusable Control Component Suite

Standardized components discoverable via the /api/v1/components endpoint.

Component Identifier Category Description Parameters
reconciliation.two_way_match Recon 2-way dataset matching across composite keys with absolute and relative tolerance. source, target, keys, compare, tolerance
tolerance.threshold_check Tolerance Single value or vector threshold breach detection. expected, actual, tolerance
quality.completeness Quality Identifies missing columns, NULLs, and blank string values. data, required_fields, allow_empty_string
quality.referential_integrity Quality Validates foreign keys in transactional feeds against parent master tables. source, lookup, foreign_key, primary_key
quality.staleness Quality Flags prices or transactions older than configured threshold days. data, timestamp_field, as_of_date, max_age_days

5. Local Setup & Quickstart Guide

Follow these steps to run the microservice locally from a clean clone.

1. Clone & Install Dependencies

# 1. Clone repository
git clone https://github.com/AmberVats/control-automation-service.git
cd control-automation-service

# 2. Create virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

# 3. Install requirements
pip install -r requirements.txt

2. Seed Data & Launch Microservice

# 1. Seed demo financial database
python -m data.seed_demo_data

# 2. Start FastAPI Server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload

# 3. Run Test Suite (55 tests)
pytest -v
